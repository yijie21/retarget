# Notice & Attribution for bundled demo data

This repository bundles a small amount of data so the side-by-side comparison demo
(`geort/mocap/compare_viser.py`) runs immediately after cloning. Please respect the
following licenses — all bundled data is for **non-commercial research/education only**.

## `data/furelise_demo.*`
A short (~20 s) clip derived from the **FürElise** dataset
(rcwang/for_elise, https://huggingface.co/datasets/rcwang/for_elise), released under
**CC BY-NC 4.0**. Only the right-hand MANO joints and mesh vertices for one excerpt are
included, re-expressed in the palm frame. Attribution per CC BY-NC; non-commercial use only.

## `data/mano_gesture.*`
A synthetic gesture sequence generated by `geort/mocap/mano_gesture.py` using the **MANO**
hand model (Max-Planck). MANO is for non-commercial use only and its license restricts
redistribution of the model and derived data. These files contain only generated 3D
keypoints and mesh vertices (no MANO model parameters). Do not use commercially.

## `data/grab_*.*`  ⚠️ PRIVATE REPO ONLY
Short clips derived from the **GRAB** dataset (https://grab.is.tue.mpg.de): `grab_s2_stapler`,
`grab_mug_drink`, `grab_teapot_pour` (subject s2). The GRAB license is **non-commercial and
forbids redistribution**. These files are included here ONLY because this repository is
**private** (personal use across your own machines). **Do not make this repository public**
while these files are present, and do not redistribute them. If you need to publish the repo,
delete `data/grab_*` first (the `.gitignore` will then keep them out).

## `checkpoint/wuji_mano/`
A pretrained GeoRT retargeting network (Wuji hand) trained on MANO-sampled data.
Non-commercial use only, consistent with the repository's CC BY-NC license and MANO's terms.

## NOT included (license forbids redistribution)
- **MANO models** (`assets/mano_v1_2/`) — download from https://mano.is.tue.mpg.de
- **Raw GRAB dataset** and other subjects — download from https://grab.is.tue.mpg.de

To regenerate any data yourself, obtain MANO (and the dataset of your choice) and follow the
"Example: Virtual Data Collection with MANO" section in the README.
